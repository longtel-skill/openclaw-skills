# 测试用例

## 用例1：查询分层含义

**输入：** "A1 A2 A3分别是什么意思？"
**预期输出：** A1订单层100%，A2框架层90%，A3商机层分阶段级别加权

## 用例2：查询A3系数计算

**输入：** "B级商机在方案评估阶段系数怎么算？"
**预期输出：** 阶段50% × 级别50% = 25%总系数

## 用例3：查询三层转化规则

**输入：** "A2拿到PO后怎么转化？"
**预期输出：** 减少对应A2金额，订单金额×100%增加到A1

## 用例4：查询A2归类条件

**输入：** "转售商业务什么时候进A2？"
**预期输出：** 同时满足：转售商合格 + 合同有持续业务潜力

## 用例5：查询年度目标计算

**输入：** "年度预算目标怎么算？"
**预期输出：** 规划预算目标 = A1 + A2 + A3，三层直接相加，每层已经加权

## 用例6：查询三层加权系数

**输入：** "A2加权系数是多少？为什么不是100%？"
**预期输出：** A2系数90%，因为框架层存在不确定性，保守反映预算预期
