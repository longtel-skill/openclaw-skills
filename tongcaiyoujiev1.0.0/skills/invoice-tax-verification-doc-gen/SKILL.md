# 发票税务核查说明文档自动生成技能

## 技能概述
本技能用于根据用户提供的核查信息，自动生成符合税务局要求格式的发票核查情况说明文档。生成的文档可以直接导出为Word文件(.docx)，用于回复税务机关的发票核查通知。

## 触发条件
以下任意关键词触发：
- 生成发票核查说明
- 税务核查回复
- 撰写发票情况说明
- 发票协查说明
- 税务发票核查回复

## 使用流程

### 第一步：收集必要信息
用户需要提供以下信息：
1. **企业名称**：被核查企业全称
2. **核查年度**：发票所属核查年度
3. **发票信息**：
   - 涉及发票份数
   - 发票金额合计
   - 税额合计
4. **核查情况**：
   - 核查结论（正常/异常/部分异常）
   - 具体情况说明（异常原因、处理情况等）
5. **回复单位**：出具说明的单位名称（通常是企业名称）
6. **回复日期**：说明文档出具日期

### 第二步：自动生成文档
技能根据提供的信息，自动：
1. 按照税务局要求排版
2. 生成标准标题
3. 整理发票统计数据
4. 撰写规范结语
5. 输出完整的Markdown文档，可转换为Word

### 第三步：导出交付
自动转换为`.docx`格式Word文档，交付用户直接打印或发送给税务局。

## 文档格式标准
生成的文档遵循以下标准结构：

```
关于[年度][企业名称]发票核查情况的说明

[税务局名称/先生/女士：]

根据贵局[核查文号/通知要求]，我司对[核查年度]涉及的发票进行了全面核查，现将核查情况说明如下：

一、企业基本情况
[企业名称]，统一社会信用代码：[XXX]，注册地址：[XXX]，主要经营业务：[XXX]。

二、发票核查情况
本次核查涉及发票共XX份，金额合计XX元，税额合计XX元，价税合计XX元。

三、核查结论
[详细说明核查结果，是否存在问题，问题发票情况，已采取的处理措施等]

四、其他说明
[如有其他需要说明的事项在此补充]

特此说明。

[企业名称（盖章）]
[日期]
```

## 工具依赖
- Python 3.x
- pandoc（用于转换Markdown到Word）
- python-docx（可选，用于直接操作Word）

## 脚本说明
`scripts/generate_doc.py`：主生成脚本，接收参数生成Markdown，然后转换为Word文档。
