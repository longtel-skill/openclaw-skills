# 差旅管理制度操作说明

## 附件

### 1 城市分类表

**一线城市**

北京、上海、广州、深圳

**二线城市**

沈阳、大连、天津、西安、成都、武汉、南京、青岛、厦门、长春、哈尔滨、兰州、重庆、郑州、杭州、宁波、无锡、苏州、福州、珠海

**三线城市**

以上未标注的均为三线城市报销标准

**城市定义**

一线城市：一般是指具有极大规模和极大国际影响力的国际级城市。

二线城市：一般是指在某一地区内具有较大规模和较大地区性影响力的地区级省级或省会级城市。

### 2 钉钉工作台《出差申请》填写说明

此页面为必填项，确保信息准确。外出申请需填写具体出差事由，如果是项目出差需填写清楚所属项目及项目编号。

如跨部门支持填选"否"，填选所支持部门，申请人自行勾选支持部门负责人。

### 3 钉钉工作台《出差申请》OA 审批流程

**3.1** 出差申请区分本部门内出差和跨部门支持出差，部门内出差直属领导根据工作情况审批出差申请，审批通过后抄送人事行政部。

**3.2** 跨部门支持出差，直属领导根据工作情况审批出差申请，审批通过后抄送人事行政部及业务所属部门负责人（需出差申请人手动勾选）。

**3.3** 请参照上图进行填写，审批通过后下载该审批单以附件形式添加至金蝶云星辰-费用报销系统中发起的此次差旅费用报销流程中。

**下载路径：** 工作台-OA 审批-已发起，选择本次提交的出差申请下载该审批单。
