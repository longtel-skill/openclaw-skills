# 差旅费报销常见问题解答 (travel-expense-faq)

本技能基于企业官方差旅费报销制度、线上报销流程管理办法、费用报销客户端操作手册，整理提供公司差旅费报销相关常见问题的标准答案，帮助员工快速查询报销规则和操作指引。

## 触发条件

以下任一触发词命中即使用本技能：
- "差旅费报销"
- "报销常见问题"
- "报销FAQ"
- "报销规定"
- "报销流程"
- "报销标准"
- "出差报销"
- "差旅费怎么报"
- "报销流程怎么走"

## 技能功能

1. **问题查询**：根据用户问题匹配对应的常见问题，给出标准解答
2. **规则查询**：查询报销标准、审批流程、发票要求等制度规定
3. **操作指引**：提供线上报销客户端操作步骤指引
4. **FAQ导出**：可导出完整常见问题文档供员工传阅

## 使用方式

### 直接问答
用户提出差旅费报销相关问题，直接匹配FAQ给出答案：
```
用户：住宿费超标怎么办？
助手：根据公司《差旅费报销制度》第X条规定...
```

### 完整FAQ导出
如需获取完整常见问题文档，可请求导出，本技能将整理为Markdown文件。

## 参考资料

本技能FAQ内容基于以下官方文档整理：
- `references/` - 存放官方制度原文、流程管理办法、操作手册

## 更新维护

当公司发布新版差旅费报销制度或流程变更时，请提供新文档更新本技能FAQ内容。

## 工作流程

1. 用户提出报销问题 → 匹配对应FAQ条目 → 返回标准解答
2. 用户提供新制度文档 → 重新整理FAQ → 更新本技能内容
3. 用户请求完整文档 → 导出完整FAQ文件

## 问答格式规范

每个问题解答遵循以下格式：
```
### Q: 问题标题
**A：** 
标准解答内容，引用制度出处
```

保持语言简洁明了，便于员工快速理解。
