# 测试用例：buyer-hw-sw-contract-review

## 说明

- **技能名称**：甲方视角审核软硬件采购合同（`buyer-hw-sw-contract-review`）
- **测试目标**：验证技能能按甲方硬性标准审核软硬件买卖合同，输出分级问题清单，并交付带修订痕迹的 `.DOCX`
- **通过标准**：关键用例须同时满足「识别正确 + 严重度分级合理 + 修订方向符合硬性标准」

---

## TC-01 触发与立场

| 项 | 内容 |
|---|---|
| 用例编号 | TC-01 |
| 用例名称 | 甲方审核触发与买方立场 |
| 前置条件 | 用户提供软硬件采购合同文本或附件 |
| 输入 | 「请从甲方视角审核这份软硬件采购合同」+ 合同全文 |
| 预期结果 | 以买方/甲方立场审核；不适用卖方视角；报告含结论摘要与问题清单 |
| 优先级 | P0 |

---

## TC-02 先票后款与分税率专票

| 项 | 内容 |
|---|---|
| 用例编号 | TC-02 |
| 用例名称 | 发票与先票后款硬性标准（货物13%/服务6%） |
| 前置条件 | 合同约定「款到后开具发票」或仅约定普通发票/未约定税率，或货物与服务混开税率 |
| 输入 | 含「买方付款后 15 日内开票」或一律按单一税率开票的软硬件+安装部署合同 |
| 预期结果 | 标为**阻断**或**须改**；修订方向为每一次付款前先开专票且先票后款；**货物/软硬件 13%**、**安装部署服务 6%**，价款分列 |
| 优先级 | P0 |

---

## TC-02A 安装部署服务与 6% 专票

| 项 | 内容 |
|---|---|
| 用例编号 | TC-02A |
| 用例名称 | 安装部署服务范围与服务费 6% 专票 |
| 前置条件 | 合同含安装部署服务费，但未约定服务范围/验收，或服务费按 13% 开票/未分列 |
| 输入 | 软硬件买卖 +「含安装调试」但无 SOW，服务费与货款混开 13% 的合同 |
| 预期结果 | 标为**须改**；补全安装部署范围、甲方依赖、交付物与验收标准；服务价款改为 **6% 增值税专用发票**并与货物价款分列；服务费宜挂钩部署/上线验收节点 |
| 优先级 | P0 |

## TC-04 付款分档（1 万 ≤ M &lt; 50 万）

| 项 | 内容 |
|---|---|
| 用例编号 | TC-04 |
| 用例名称 | 中额合同付款比例 |
| 前置条件 | 合同总价 20 万元 |
| 输入 | 约定「合同签订后 100% 预付」的合同 |

| 优先级 | P0 |

## TC-05 付款分档（M ≥ 50 万）

| 项 | 内容 |

| 前置条件 | 合同总价 80 万元 |

| 预期结果 | 标为**须改**；修订为至少三次：发货前 30%、初验 30%、终验 40% |
| 优先级 | P0 |

## TC-09 验收与交付

| 项 | 内容 |
|---|---|
| 用例编号 | TC-09 |
| 用例名称 | 验收标准模糊 |
| 前置条件 | 验收约定为「甲方合理满意即视为验收通过」 |
| 输入 | 无量化验收标准、无不合格处理的软硬件合同 |
| 预期结果 | 列入问题清单；建议补全可测试验收标准及返修/替换/退款规则；金额 ≥50 万时须能支撑三次付款节点 |
| 优先级 | P1 |

|---|---|

## 回归检查清单

执行完整审核场景时，确认输出同时覆盖：

- [ ] 结论摘要（是否建议签约 + 硬性标准符合情况，含货物13%/服务6%）
- [ ] 合同定性与付款档位；货物与安装部署服务价款分项
- [ ] 安装部署范围/验收（合同含服务时）
- [ ] 按严重度分级的问题清单（引用条款位置/摘录）
- [ ] 谈判/修改方向
- [ ] 声明：不构成法律意见
- [ ] 最终 `.DOCX` 带修订痕迹
