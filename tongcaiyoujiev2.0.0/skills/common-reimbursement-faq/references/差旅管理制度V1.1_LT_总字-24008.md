## 1. 目的

为明确公司差旅政策，优化差旅管理流程，控制差旅成本，实现差旅活动的合规、高效、经济和安全，同时贯彻勤俭节约、艰苦奋斗的原则，特制定《差旅管理制度V1.1》。

## 2. 适用范围

本制度适用于总公司及各分子公司全体员工。

## 3. 各部门职责

### 3.1 组织发展中心 --- 人事行政部

负责制定出差管理流程，明确各项标准，维护因出差引起的考勤异动。

### 3.2 财务中心 --- 财务部

负责根据《线上费用报销流程管理办法V1.0》LT综（财）字---24001，审核凭证的真实性与有效性，把控费用并处理报销事宜。

### 3.3 出差人员

依照本制度规定提起出差申请并根据《线上费用报销流程管理办法V1.0》LT综（财）字---24001，报上级领导审批，并对真实性和票据的合法性负责。

### 3.4 部门负责人

部门负责人指差旅费用支出归口部门负责人，负责对差旅费用报销进行核准和批示，负责对差旅费用支出进行预算把控。

## 4. 差旅管理标准及原则

### 4.1 差旅管理标准

#### 4.1.1. 出差时间

4.1.1.1. 出差时间以路途交通票据上时间为准；

4.1.1.2. 出差返程当日计算时间界定：

| 出差时间界定 | 时间 | 天数 | 备注 |
|-------------|------|------|------|
| 出发当天 | 中午12：00前 | 1天 | 出差时间大于0.5天则不享受当天午餐补助及交通补助 |
| 出发当天 | 中午12：00后 | 0.5天 | |
| 返回当天 | 中午12：00前 | 0.5天 | |
| 返回当天 | 中午12：00后 | 1天 | |

4.1.1.3. 原则上工作日和周末出差均不计算加班。

#### 4.1.2. 出差审批流程

4.1.2.1. 因工作业务需要员工确有必要出差的，需将出差事由、时间汇报部门负责人，经部门负责人批准后，**应至少提前一个工作日**在钉钉工作台 OA 审批处填写《出差申请》，《出差申请》中应据实填写出差时间、事由、目的地、所乘交通工具以及出差期间的工作交接等相关项目。

4.1.2.2. 《出差申请》填写完成且经逐级审批同意后，方可出差；

4.1.2.3. 出差人员应先行垫付出差费用，出差完毕后依照本制度第 4条第 4.2款规定进行报销；

4.1.2.4. 因公务紧急，未能履行出差审批手续的，出差前可以电话或短信方式向直属领导（部门负责人）请示，并于获批后 **24小时内** 在钉钉工作台 OA 审批处提交《出差申请》手续；

4.1.2.5. 如遇特殊情况或未尽事宜需提前以邮件方式发起申请至部门负责人审批，抄送人事行政部负责人及财务部负责人，获批后方可进行。

### 4.2 差旅管理原则

4.2.1 差旅费用支出必须遵守"预算控制、勤俭节约"的原则，员工尽可能在预算范围内，做好日程计划及费用安排；

4.2.2 所有差旅费用开支一律凭正式发票报销，涉及行政事业性收费可以使用相应收据；

4.2.3 差旅费用报销时，以钉钉工作台《出差申请》获批时间段内所产生的所有费用进行**一次性申报**，严禁拆分多单报销；

4.2.4 无论报销增值税专用发票还是增值税普通发票，都必须正确填写公司名称及税号，不符合规定的发票一律不予报销。

## 5. 差旅费报销

差旅费指公司员工因公出差到非常驻地点所发生的合理支出，仅包含住宿费、交通费。

### 5.1 差旅交通及住宿费用标准

### 5.2 差旅费报销要求

5.2.1 差旅费用报销需要出差人员依照《线上费用报销流程管理办法V1.0》LT综（财）字--- 24001在金蝶云星辰-费用报销系统发起费用报销流程，且需于费用发生后的 **30个自然日内** 完成报销申请，超期将不予报销，发起费用报销流程审批时需添加钉钉出差申请为附件进行核对（具体流程如附件所示）。特殊情况需部门负责人以邮件形式批准方可报销；

5.2.2 员工因公出差发生的费用（个人订票机票报销需提供**发票+登机牌/行程单**）、火车费凭有效票据报销，票据所示日期、往返地须与实际出差日期、出差地一致；票据载有旅客姓名的所载姓名必须与实际出差人一致。机票保险额最高**30元/单程**；

5.2.3 因员工个人原因，如订错票、误机、升舱等造成退/换票的，费用由员工个人承担。因公退、换票的，需在报销时另行说明，并提供正式票据，由上级领导审批同意后方可报销；

5.2.4 员工出差期间因个人原因从第三地返回公司的，只报销到出差地的往返交通费；

5.2.5 打车出行：出租车及快车可实报实销，需提供发票及行程单，快车以上打车方式按经济型网约车价格标准进行报销。私家车自驾出差须向上级领导提出申请，审批通过后以**1元/公里**标准，核实实际发生里程并进行报销。报销时需在事项中列明出发地、目的地、公里数，同时需附高速收费凭证、百度/高德导航行驶公里数，提供对应金额加油票方可进行自驾差旅费用报销。出于安全考虑自驾目的地限定在**400公里范围内**；

5.2.6 因会务需要，由举办方指定酒店和住宿的情况，如超出本制度第5条第5.1款规定的费用标准，员工需提交举办方统一安排证明并开具住宿发票，以确保报销的合规性及真实性；

5.2.7 员工参加展会、市场推广会、培训等活动期间，由公司或会议主办单位统一安排食宿的，公司不再承担额外住宿费，**仅享受出差补助**。

5.2.8 员工出差期间，因游览或非工作需要的参观而开支的一切费用，均由个人自理；

5.2.9 自驾出差的，行车期间产生的油料费、过桥费、停车费等国家或地方政府规定的应收费用可凭消费票据进行报销。由于个人违章所造成的罚款一律不得报销。
