## 回答准确性测试用例

### 差旅费报销问答
| 问题 | 预期回答关键点 | 测试结果 |
|------|---------------|----------|
| 差旅费报销的基本流程是什么？ | 出差申请→借款→返程报销→审批→财务审核打款 | 通过 |
| 市内交通补助标准是多少？ | 100元/天，半天减半 | 通过 |
| 住宿费报销标准是多少？ | 按职级对应标准，超标部分自理 | 通过 |
| 哪些交通费用可以报销？ | 飞机、高铁、大巴、出租等合理交通费用凭票报销 | 通过 |
| 出差补助怎么计算？ | 按出差天数×每日标准 | 通过 |
| 发票需要什么要求？ | 公司抬头、税号正确，电子/纸质均可，需要验真查重 | 通过 |
| 线上报销如何上传附件？ | 在客户端选择上传按钮，支持PDF/JPG/PNG | 通过 |

### 通用费用报销问答
| 问题 | 预期回答关键点 | 测试结果 |
|------|---------------|----------|
| 非项目借款审批流程是什么？ | 本部门负责人审批 | 通过 |
| 项目借款审批流程是什么？ | 项目负责人审批，需要填写项目编号 | 通过 |
| 下拉菜单里找不到我要找的项目编号？ | 联系财务中心添加对应项目信息 | 通过 |
| 报销发票为什么需要验真？ | 保证发票真实有效，防止假票入账 | 通过 |
| 哪些发票不能报销？ | 假票、抬头税号错误、过期发票、内容与业务不符 | 通过 |
| 付款完成后会通知我吗？ | 付款完成后系统会更新状态，可在系统中查询 | 通过 |
| 金蝶云星辰登录地址是什么？ | 按公司统一入口登录，由IT部门统一分配账号 | 通过 |
| 报销款项多久能到账？ | 审核通过后一般3-5个工作日 | 通过 |
