## 回答准确性测试用例

| 问题 | 预期回答关键点 | 测试结果 |
|------|---------------|----------|
| 差旅费报销的基本流程是什么？ | 线上申请→提交审批→财务审核→打款 | |
| 住宿费报销标准是多少？ | 按职级对应标准，超标自理/按标准报 | |
| 哪些交通费用可以报销？ | 飞机、高铁、大巴、出租等合理交通费用 | |
| 出差补助怎么计算？ | 按出差天数×每日标准 | |
| 发票需要什么要求？ | 公司抬头、税号正确，电子/纸质均可 | |
| 线上报销如何上传附件？ | 在客户端选择上传按钮，支持PDF/JPG | |
| 审批流程需要多久？ | 按审批层级，一般1-3个工作日 | |
| 报销款项多久能到账？ | 审核通过后3-5个工作日 | |
