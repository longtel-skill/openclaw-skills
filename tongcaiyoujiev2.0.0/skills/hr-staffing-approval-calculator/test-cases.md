# 测试用例

本清单覆盖 hr-staffing-approval-calculator 的正常场景与边界场景。示例参数均为演示用，不代表任何真实申请。

---

### 测试用例 1：正常场景 - 3 人申请，全年营业额 174 万
**输入参数**
- 申请人数：3 人
- 全年营业额：174 万元
- 目标毛利率：0.30

**预期结果（按示例默认阈值）**
1. 人均产值 = 174 ÷ 3 = 58 万元/人 ≥ 50 → 通过
2. 毛利率 0.30 ≥ 0.25 → 通过
3. 总薪资上限 = 174 × 0.25 = 43.50 万元/年
4. 人均年薪上限 = 43.50 ÷ 3 = 14.50 万元/人/年

**实际结果：** 计算正确，通过
