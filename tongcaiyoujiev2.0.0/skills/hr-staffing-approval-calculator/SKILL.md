# 人力编制审批测算技能（通用模板）

## 概述

本技能对部门新增人力申请做合规测算：给定全年营业额、申请人数与目标毛利率，按**可配置阈值**判断申请是否通过，并给出合规薪资上限与人均上限。

本技能不含任何特定组织的审批口径；下表阈值均为示例默认值，请按实际管理口径传入。

## 可配置阈值

| 参数 | 含义 | 示例默认值 |
|------|------|-----------|
| --min-revenue-per-head | 人均产值门槛（万元/人/年） | 50 |
| --min-margin | 最低毛利率 | 0.25 |
| --payroll-cap-ratio | 薪资上限占营业额比例 | 0.25 |
| --bonus-margin | 触发超额奖金的毛利率阈值 | 0.50 |
| --bonus-ratio | 超额奖金计提比例（按实际毛利） | 0.10 |

## 工作流：四步审批法

### 第一步：人均产值门槛核查
实际人均产值 = 全年营业额 ÷ 申请人数；低于门槛 → 不通过。

### 第二步：毛利率底线核查
目标毛利率低于下限 → 不通过。

### 第三步：计算总薪资上限
总薪资上限 = 全年营业额 × payroll-cap-ratio；人均年薪上限 = 总薪资上限 ÷ 申请人数。

### 第四步：超额奖金（可选）
毛利率超过 --bonus-margin 时，奖金 = 实际毛利 × --bonus-ratio，单独计发，不计入总额上限。

## 脚本

scripts/staffing_approval_calculator.py，仅依赖 Python 3 标准库：

    python3 scripts/staffing_approval_calculator.py --revenue 1000 --headcount 5 --margin 0.35
