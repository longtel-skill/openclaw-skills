# 测试用例

## 用例1：查询开票前提条件
- **输入：** 申请开具发票需要满足哪些条件？
- **预期输出：** 返回完整三条前提条件及注释内容
- **状态：** 通过

## 用例2：查询退票流程
- **输入：** 发票退票流程是什么？
- **预期输出：** 返回完整两步退票流程
- **状态：** 通过

## 用例3：查询一对多开票
- **输入：** 什么是一对多开发票？
- **预期输出：** 返回两种情况的定义
- **状态：** 通过

## 用例4：未收录问题
