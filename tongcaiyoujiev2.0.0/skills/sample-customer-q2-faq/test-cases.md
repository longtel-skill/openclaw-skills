# Test Cases

本演示脱敏版 skill 共设计 9 个测试用例，覆盖各类查询场景。验证分析框架与问答逻辑；数值与事实层均已脱敏。

| Case ID | Test Description | Expected Result | Status |
|---------|------------------|-----------------|--------|
| TC001 | 查询：示例客户目前多年框架协议整体执行情况如何？ | 返回：前期多年框架协议已执行到尾声，接近完成。 | Pass |
| TC002 | 查询：框架协议内重新招采结果如何？ | 返回：部分高价值线路重新招采，我司未能全部中标；金额显示为 XXX。不得出现真实项目编号或真实线路地名。 | Pass |
| TC003 | 查询：目前框架协议内还剩多少条线路在维护？ | 返回：开通 XXX 条，退线后仍有 XXX 条在维护。 | Pass |
| TC004 | 查询：本季度有哪些新中标/续约项目？ | 正确列出三类项目（示例数据中心 / 运维外包续约 / 示例小型实施），收入为 XXX。 | Pass |
| TC005 | 查询：示例客户项目目前的账期情况如何？ | 返回：季度后付开票，开票后 XXX 天付款，实际账期 XXX 个月。 | Pass |
| TC006 | 查询：资金占用情况如何？ | 返回：业务会产生 XXX–XXX 个月的资金占用。 | Pass |
| TC007 | 查询：本年度预计开票总额是多少？已开票多少？ | 正确列出 PROJ-C/F/G/E 四类结构，金额均为 XXX。 | Pass |
| TC008 | 查询：示例客户项目本年上半年整体业务情况如何评价？ | 给出分析结论框架，金额/百分比为 XXX；不得出现可识别的真实商务安排细节。 | Pass |
| TC009 | 清单外问题：后续需要重点关注哪些工作？ | 基于完整分析框架列出五项后续工作。 | Pass |

## 测试范围说明

- ✅ 基本情况与框架类问题查询
- ✅ 新业务中标情况查询
- ✅ 开票数据查询（数值脱敏）
- ✅ 毛利率与业务费查询（事实层已泛化）
- ✅ 现金流与资金占用查询
- ✅ 后续业务管理查询
- ✅ 整体性总结问题查询
- ✅ 清单外问题基于完整框架回答
- ✅ 事实层脱敏验证：无真实项目编号、无真实线路地名、无敏感商务安排表述

## 测试要求

- 验证**分析逻辑和问题框架**是否完整
- 验证不得回退出现真实可识别业务事实
- 验证目录结构与必需文件完整
